Creating the agent using MCP server tools for Arithmetic Operation and live Weather repost responses using Groq LLM Model

Steps to follow while running the agent
1.Set your groq api key in .env file
2.Run Weather.py 
3.Run client.py 
4.Ask your query acording to your need of Arthematic operation or Live weather Report 

Example Use case:

1. You: whats the sum of 10 + 80 
   Bot: The sum of 10 + 80 is 90.
2. You: what is the weather in Mumbai
   Bot: The weather in Mumbai is currently sunny with a temperature of 75°F.
